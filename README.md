<h4>1. Class vs Struct vs Record</h4>
<h5>Class</h5>
<p>reference type .</p>
<p>Used to create objects that contain data and methods.</p>
<p>Supports inheritance from other classes.</p>

<h5>Struct</h5>
<p>value type .</p>
<p>Commonly used to represent small values, such as points or coordinates.</p>
<p>Cannot inherit from another class or struct, but can implement interfaces.</p>

<h5>Record</h5>
<p>Used mainly to represent data.</p>
<p>Supports value-based equality by default.</p>
<p>Can be a record class (reference type) or a record struct (value type).</p>

<h4>what is the indexer</h4>
<p>An indexer allows an object to be accessed using square brackets[]</p>
